# 🏨 Hôtel La Vôtre – Site de Réservation

Site web de réservation pour l’**Hôtel La Vôtre** (Quelkoura), développé dans le cadre d’un projet de fin d’études en **BTS Développement Web et Mobile**.

## 🌐 Fonctionnalités

- ✅ Consultation des chambres avec **équipements**, services et prix (en **FCFA**)
- ✅ Réservation en ligne avec **confirmation par email**
- ✅ Interface administrateur sécurisée (JWT) pour gérer :
  - Chambres, équipements, services
  - Réservations (CRUD + validation)
  - Messages clients
  - Menu du restaurant
- ✅ Responsive design (mobile, tablette, desktop)

## 🛠️ Technologies utilisées

- **Frontend** : React.js, Vite, Tailwind CSS
- **Backend** : Node.js, Express.js
- **Base de données** : MySQL
- **ORM** : Sequelize
- **Authentification** : JWT + Bcrypt
- **Email** : Nodemailer (Gmail)
